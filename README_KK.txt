# MoveClass — DamuSport

Бұл нұсқада MoveClass сайты OpenAI API арқылы нақты AI сабақ жоспарын сұрата алады.

## Қажет болады
- Node.js орнатылған компьютер
- OpenAI API кілті және API қолдану мүмкіндігі/төлемі бапталған есептік жазба

## Іске қосу (Windows)
1. Осы буманы компьютерге шығарыңыз.
2. Буманың ішінде терминал/CMD ашыңыз.
3. `npm install` командасын орындаңыз.
4. `.env.example` файлының көшірмесін жасап, атын `.env` деп өзгертіңіз.
5. `.env` ішіндегі `OPENAI_API_KEY` мәніне өз API кілтіңізді енгізіңіз.
6. `npm start` командасын орындаңыз.
7. Браузерден `http://localhost:3000` ашыңыз.

## Қауіпсіздік
API кілтін сайттың HTML/JavaScript ішіне жазбаңыз, ешкімге жібермеңіз және GitHub-қа жүктемеңіз. Кілт сервердегі `.env` файлында ғана сақталуы керек. Егер кілт жария болып кетсе, оны API басқару панелінен өшіріп, жаңасын жасаңыз.

Бұл оқу жобасының көмекші құралы. AI ұсынған жоспарды мұғалім оқу бағдарламасына, оқушының нақты дайындығына және қауіпсіздік талаптарына қарай міндетті түрде тексеріп, бейімдеуі тиіс.
